### What is Obsidian

Obsidian is a local-first knowledge management application built around Markdown files. Its strength is that it combines document authoring, linked knowledge, databases, visual thinking, and extensibility through plugins.

You can understand its capabilities in six major functional categories:
1. **Knowledge Management** – Notes, links, tags, properties.
    
2. **Information Organization** – Bases, folders, metadata.
    
3. **Visual Thinking** – Canvas, Excalidraw, Graph View.
    
4. **Navigation** – [[Quick Switcher]], Search, Backlinks.
    
5. **Working Environment** – Workspace, panes, tabs.
    
6. **Automation and Extensibility** – Templates, commands, plugins.
    
Let's examine the important functions individually.

### **A. Bases – Database and structured information management**

Core plugin

[Introducción a Bases - Ayuda de Obsidian](https://images.openai.com/static-rsc-4/vOExGpVa5gFO1TtdB9svWxb9JXdyDUIiW0w3yijYQNOapSwrPYCEmv0zFPME3aYO3q_N0DHSMS3Hk8nRKTlNL52Is-JGyW1yzP_9snovJxBnsr5sWkAknxFTBNdNIj2rJlha3r07Jojnid7D2PBxakFGyIKzc-GZ-PtXhvsTNTk?purpose=inline)

[obsidian.md](https://obsidian.md/es/help/bases?utm_source=chatgpt.com)

**Bases** turns your Markdown notes into database-like collections.

It allows you to organize and manage notes using their properties (metadata), without moving the information into an external database.

---
#### Key functions:

| Function       | Description                                     |
| -------------- | ----------------------------------------------- |
| Table View     | Display notes as rows and properties as columns |
| Cards View     | Display notes as visual cards                   |
| Filtering      | Extract notes matching specified conditions     |
| Sorting        | Sort by date, status, category, etc.            |
| Grouping       | Group records by property values                |
| Formulas       | Calculate derived values from properties        |
| Multiple Views | Maintain different views of the same data       |

---

**Example: Project Management Base**

| Project         | Status      | Priority | Category |
| --------------- | ----------- | -------- | -------- |
| ERP Renewal     | In Progress | High     | IT       |
| AI Architecture | Planning    | High     | Research |
| Data Migration  | Completed   | Medium   | IT       |

You can create different views:

- Active Projects
    
- High Priority Projects
    
- Completed Projects
    
- Projects by Category
    

**When to use it:** Project portfolios, requirements catalogs, architecture inventories, risk registers, task management, and knowledge indexes.

Official guide: [Obsidian Bases documentation](https://obsidian.md/help/Plugins/Bases?utm_source=chatgpt.com).

Instead of searching through folders manually, you can quickly find and open a note by typing part of its name.

---

#### Key functions:

- Search notes by filename.
    
- Find notes using partial words.
    
- Open an existing note.
    
- Create a new note if the requested name does not exist.
    
- Navigate your vault without using the mouse.
    

**Typical shortcut:**

- Windows/Linux: `Ctrl + O`
    
- macOS: `Cmd + O`

---

Example:

Type `Architecture` to find notes such as:

- Enterprise Architecture
    
- System Architecture
    
- Software Architecture
    
- Architecture Principles
    

**When to use it:** Daily navigation, particularly when your vault contains hundreds or thousands of notes.

## **5. Which functions should you learn first?**

My suggested learning sequence:

1. **Markdown + Properties + Internal Links**
    
    Learn how to create notes, define metadata, and connect information.
    
2. **Quick Switcher + Search + Backlinks**
    
    Learn how to navigate and retrieve knowledge efficiently.
    
3. **Workspace**
    
    Establish separate working environments for research, architecture, and project management.

---
1. **Bases**
    
    Build structured information management and project databases.
    
2. **Canvas + Excalidraw**
    
    Develop visual thinking and architecture modeling capabilities.
    
3. **Templates + Community Plugins**
    
    Automate repetitive knowledge management activities.

**My overall perspective:** Obsidian is more than a note-taking application. It can serve as a personal knowledge engineering environment, combining structured information, conceptual relationships, visual models, and reusable working processes.

A particularly useful approach is to treat **Markdown as the knowledge repository, Bases as the information management layer, Canvas as the conceptual modeling layer, and Excalidraw as the diagramming layer.**

This creates a coherent environment for developing and maintaining system architecture knowledge.
